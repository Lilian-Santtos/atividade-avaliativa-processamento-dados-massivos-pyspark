## Objetivo

Aplicar conceitos introdutórios de processamento de dados massivos utilizando **Apache Spark com PySpark**, trabalhando com uma base de dados de corridas de táxi de Nova York.

A atividade aborda operações de seleção, filtragem, agrupamento, agregação e junção de dados, além de conceitos relacionados ao funcionamento do Spark.

---

## Tecnologias utilizadas

- Python
- PySpark
- Apache Spark
- Google Colab
- GitHub

---

## Conteúdo da atividade

O notebook apresenta a resolução de 10 questões envolvendo:

- leitura e análise do schema de um DataFrame;
- seleção de colunas;
- filtragem de registros;
- `inferSchema` e definição manual de schema;
- agrupamentos e agregações com `groupBy`;
- análise de dados por hora;
- transformations, actions e lazy evaluation;
- criação de novas colunas;
- cálculo de percentual de gorjeta;
- join entre DataFrames;
- análise do impacto de shuffle no processamento.
